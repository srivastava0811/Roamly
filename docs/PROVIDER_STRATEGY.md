# Provider Gateway Strategy & Fallback Architecture

> **Guiding Principle**: Free-tier and open-source first. Zero automatic paid provisioning.
> **Total External Infrastructure Budget Ceiling**: $40–$60 total.
> **Recurring Infrastructure Cost Goal**: $0/month during active development.

---

## 1. Provider Ecosystem & Free-First Priority

To achieve maximum reliability without incurring cloud provider bills, every external service category adopts a **tiered fallback hierarchy**:
1. **Tier 1 (Default)**: Offline Deterministic Fixtures / Local Cache.
2. **Tier 2 (Open Free Tier)**: Open-source, rate-limited public APIs (Open-Meteo, OpenStreetMap / MapLibre, OSRM).
3. **Tier 3 (Commercial Free Tier)**: Eligible developer free quotas (Supabase, Gemini Flash API).
4. **Tier 4 (Paid Add-On)**: strictly requires explicit human developer approval.

```mermaid
flowchart LR
    Request[Domain Service Request] --> Gateway[Provider Gateway]
    Gateway --> Cache{Local Cache Hit?}
    Cache -- Yes --> ReturnCache[Return Cached Result (source: cached_provider)]
    Cache -- No --> CheckQuota{Within Free Quota?}
    CheckQuota -- Yes --> CallFree[Call Free Provider (Open-Meteo, OSRM, Supabase)]
    CheckQuota -- No / Disabled --> ReturnMock[Return Deterministic Mock Fixture (source: fixture_mock)]
    CallFree --> Provenance[Attach Provenance Metadata & Confidence Score]
    ReturnMock --> Provenance
    Provenance --> Response[Return ProviderResult to Domain Service]
```

## 2. Category-Specific Strategies

### 2.1 Places & POIs
- **Primary Open Provider**: OpenStreetMap Nominatim / Overpass API.
  - *Terms*: 1 request/sec max, valid User-Agent required, no commercial scraping.
- **Offline Fallback**: `MockPlacesProvider` returning realistic categorized POIs.
- **Future Production Option**: Google Places API or Foursquare API (deferred until commercial monetization).

### 2.2 Maps & Visualization
- **Primary Open Provider**: MapLibre GL JS with free public vector tiles (Demotiles, OpenMapTiles, or Stamen OSM styles).
  - *Cost*: $0. Vector rendering client-side in browser/canvas.
- **Mobile Integration**: React Native MapLibre or native platform Apple Maps / Google Maps basemap.

### 2.3 Routing & Directions
- **Primary Open Provider**: Open Source Routing Machine (OSRM) public demo server or self-hosted container.
- **Offline Fallback**: Deterministic Haversine distance calculator with speed-profile multiplier (`calculateHaversineDistanceKm`).
- **Commercial Alternative**: GraphHopper free tier (500 requests/day).

### 2.4 Weather & Climate
- **Primary Open Provider**: Open-Meteo API.
  - *Terms*: Free for non-commercial and commercial use under 10,000 daily API calls! No API key required.
  - *Capabilities*: Multi-day temperature, rain probability, wind speed, UV index.
- **Offline Fallback**: `MockWeatherProvider` providing seasonal norms.

### 2.5 Flights & Long-Distance Transit
- **Strategy**: Flight data is notoriously expensive with zero free production commercial APIs.
  - *Development Mode*: `MockFlightsProvider` provides realistic flight options with standard carrier IATA codes and deep-link generation.
  - *Free Tier Testing*: Amadeus for Developers Self-Service Free Tier (2,000 free monthly test calls).
  - *Crucial Rule*: Never hallucinate fake live flight prices. Output must clearly state `source: fixture_mock` or `source: deterministic_estimate`.

### 2.6 Lodging & Accommodation
- **Strategy**:
  - *Development Mode*: `MockLodgingProvider` returning curated sample boutique hotels, hostels, and apartments.
  - *Evaluation Option*: Booking.com Affiliate API or RapidAPI free-tier hotel aggregators (strictly opt-in).

### 2.7 Public Transit & Mobility
- **Primary Open Provider**: Transitland open transit data platform or local GTFS feeds.
- **Offline Fallback**: `MockTransitProvider` with realistic city subway/bus intervals and flat-fare estimates ($2.50).

## 3. Provenance & Confidence Tagging

To prevent user deception and ensure auditability, every response returned by the provider gateway is wrapped in `ProviderResult[T]` with explicit provenance:

| Provenance Source | Meaning | UI Indicator |
|---|---|---|
| `live_provider` | Fetched in real time from live third-party API | Green checkmark ("Live Data") |
| `cached_provider` | Valid cached record from recent provider lookup | Blue clock ("Updated 2h ago") |
| `deterministic_estimate` | Computed via mathematical algorithms (Haversine distance, standard mileage rates) | Amber badge ("Calculated Estimate") |
| `ai_synthesized` | Generated by Gemini model (e.g. packing advice, itinerary commentary) | Purple sparkle ("AI Recommended") |
| `fixture_mock` | Offline development fixture or simulated schedule | Gray badge ("Dev Fixture") |
| `user_override` | Manually edited or customized by the traveler | Slate user icon ("Custom Entry") |

## 4. Quota Controls, Retries, and Circuit Breakers

1. **In-Memory Rate Limiting**: Token-bucket algorithm prevents exceeding public free rate limits (e.g. Nominatim 1 req/sec).
2. **Exponential Backoff**: Transient HTTP 429 and 503 errors trigger backoff: $t = 2^n \times 250\text{ms}$ up to 3 retries.
3. **Circuit Breakers**: If an external provider fails 5 consecutive times within 60 seconds, the gateway trips to open state and routes calls directly to mock fixtures for 5 minutes, preventing cascade latency.
4. **Caching Layer**: All responses are cached keyed by normalized query parameters with category-appropriate TTLs:
   - Weather: 6 hours.
   - Places & POIs: 7 days.
   - Routing: 24 hours.
